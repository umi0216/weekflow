# 同频 · 团队协作

精简的团队任务看板。成员导航、四阶段任务流，操作优先。

- 四阶段：待办 → 进行中 → 待检查 → 已完成。
- 新建任务默认待办，自动记录创建时间。双击待办空白区新建；单击卡片编辑，双击卡片推进，也支持拖动和状态选择。
- 按创建周分组（周一到周日），支持收起、筛选、搜索及列表视图。
- 每位成员有独立空间，全部视图汇总团队任务。
- 看板只显示标题、日期和必要标记；描述、时间记录在详情中查看。
- 常用操作使用图标，悬停查看名称；键盘聚焦和触屏均可操作。
- 示例模式与真实数据库隔离；进入示例不会写入真实数据。
- 数据保存在服务端；任务更新有版本检查，避免多人操作时无提示覆盖。

## 本地运行

需要 Node.js 22.13 或更新版本，推荐 Node.js 24+（内置 SQLite）。无需安装第三方依赖。

```powershell
npm run dev
```

打开 http://127.0.0.1:4173 。本地数据保存在 `.runtime/team.sqlite`，重启保留。不要删除此文件，定期备份整个 `.runtime` 目录。

如需在可信的公司局域网使用，Linux / macOS 下执行：

```bash
HOST=0.0.0.0 npm run dev
```

其他设备访问 `http://服务器的局域网IP:4173`，不要访问 `0.0.0.0`。环境变量需与启动命令写在同一行，或先用 `export HOST=0.0.0.0` 导出。访问控制由公司网络提供；成员空间用于分类任务，成员姓名不是登录账户。默认本地服务仅监听本机。

```powershell
npm test
npm run build
```

## 构建与部署

`npm run build` 生成 `dist/server/index.js`，是包含前端资源与接口的自包含 Cloudflare Worker，不依赖外部 CDN。构建只生成本地文件，不会上传或发布。

自行部署时，配置名为 `DB` 的 Cloudflare D1 数据库绑定，并应用 `drizzle/` 中的 SQL 迁移。D1 与本地 SQLite 是两个独立数据库；团队共享的访问控制由部署环境配置。

源码可直接提交到自己的 Git 仓库。数据库、测试截图、浏览器缓存、构建产物及本地环境配置均由 `.gitignore` 排除。

快捷键：N 新建任务、/ 搜索、Enter 编辑选中卡片、Ctrl/⌘ + Enter 保存、Esc 关闭弹窗。
