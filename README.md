# 同频 · 团队协作

小而美的内部协作看板。先创建成员，再进入成员空间管理任务。

- 四阶段：待办 → 进行中 → 待检查 → 已完成。
- 新建任务默认待办，自动记录创建时间。单击编辑，双击推进，也支持拖动和状态选择。
- 按创建周分组（周一到周日），支持收起、筛选、搜索及列表视图。
- 每位成员有独立空间，团队总览汇总全部进展。
- 示例模式与真实数据库隔离；进入示例不会写入真实数据。
- 数据保存在服务端；任务更新有版本检查，避免多人操作时无提示覆盖。

## 本地运行

需要 Node.js 22.13 或更新版本，推荐 Node.js 24+（内置 SQLite）。无需安装第三方依赖。

```powershell
npm run dev
```

打开 http://127.0.0.1:4173 。本地数据保存在 `.runtime/team.sqlite`，重启保留。不要删除此文件，定期备份整个 `.runtime` 目录。

如需在可信的公司局域网使用，可设置 `HOST=0.0.0.0` 后启动，并由公司网络提供访问控制。成员空间用于分类任务，成员姓名不是登录账户。默认本地服务仅监听本机。

```powershell
npm test
npm run build
```

## 托管

`.openai/hosting.json` 保留 Sites 项目身份并声明 D1 数据库绑定。`npm run build` 生成自包含 Cloudflare Worker，前端资源与接口在同一域名，不依赖外部 CDN。

SQL 迁移位于 `drizzle/`，托管发布由 Sites 应用。新站默认私密，仅所有者可访问；团队共享需在站点访问权限中明确配置。托管 D1 与本地 SQLite 是两个独立数据库。

快捷键：N 新建任务、/ 搜索、Enter 编辑选中卡片、Ctrl/⌘ + Enter 保存、Esc 关闭弹窗。
